Phase 1: Project Foundation Active

Active configuration controls and toggles are deliberately withheld in this foundation release. ScrollShield does not display inert or misleading toggles. The controls previewed below outline the exact functionality coming in upcoming phases.

Planned Configuration Controls

The following controls are scheduled for implementation in Phase 2 and subsequent releases:

Upcoming

Selective Platform Filtering

Granular filtering that suppresses high-friction dopamine loops while preserving essential features.

  • YouTube: Block Shorts feed & reels player while preserving search, long-form videos, and subscriptions.
  • Instagram: Block Reels surface and explore video grid while leaving Direct Messages (DMs) accessible.
Upcoming

Reflective Intervention Prompts

Mindful interstitial checkpoints designed to interrupt subconscious scrolling triggers.

  • Custom Questions: Configure personal reflection prompts before accessing target URLs.
  • Intervention Delay: Set an intentional pause duration (5 to 30 seconds) before proceeding.
Upcoming

Daily Usage Budgets

Time-capped allowances for selected recreational web platforms.

  • Budget Allocation: Daily caps per service or pooled across all distraction targets.
  • Gentle Warnings: Visual reminders when approaching 80% and 100% of daily allotment.
Upcoming

Focus Schedules & Quiet Blocks

Automated scheduling to lock down distracting surfaces during deep work intervals.

  • Workday Schedules: Define active days and time windows (e.g. 09:00 - 17:00).
  • Strict Mode: Disallow manual overrides during active focus periods.

Data Privacy & Architecture

ScrollShield adheres to a zero-telemetry, offline-first philosophy:

  • All configurations and metrics are stored strictly on your device via Chrome's local storage.
  • No external servers, tracking scripts, third-party analytics, or remote API endpoints.
  • Minimal permissions: permissions are requested only when concrete functionality strictly requires them.
